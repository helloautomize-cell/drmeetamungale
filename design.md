You are now acting as the lead product designer, art director, UX designer, and senior frontend engineer for the Mungale Eye Hospital website.

IMPORTANT:
Do not treat this as a generic hospital website redesign.
The goal is to create a premium, emotionally intelligent, human-first medical website that immediately creates trust between a patient and the doctors.

The website must feel:
- calm
- human
- credible
- editorial
- premium
- warm
- precise
- modern
- Indian and real
- doctor-led
- patient-first

It must NOT feel:
- like Practo
- like Apollo
- like a hospital template
- like a SaaS landing page
- like a startup website
- like a futuristic WebGL experiment
- like a luxury cosmetic clinic
- like a generic Tailwind template

Study the visual principles behind:
- PRAXIS4

- Dr Agnes Chang

- APDERM
- Under My Skin
- BioLine Workshop

Extract the principles:

- subtle motion
- clear information hierarchy
- restrained interaction
- confidence without aggressive marketing

BRAND:
The Mungale logo cannot be changed.
The existing red must remain the brand red.
Do not redesign, recolor, simplify, redraw, distort, or replace the logo.

Use the red as an accent, not as the dominant surface color.

Target approximate visual ratio:
- 70 to 80% warm white / paper / neutral
- 15 to 25% black / charcoal
- 5 to 8% Mungale red

Use a warm off-white rather than pure white.
Suggested background: #F7F5F0 or a very similar warm neutral.
Suggested text: #121212.
Use the logo red as the exact brand red, approximately #ED2225.
Do not introduce a competing red.

TYPOGRAPHY:
Use one distinctive editorial serif for major headings.
Prefer something with character such as Instrument Serif or another refined editorial serif already available in the project.

Use a clean modern sans-serif for body text, navigation and UI, such as Manrope or Inter.

The serif should communicate humanity and confidence.
The sans-serif should communicate precision and medical clarity.

Do not use giant bold sans-serif headings throughout the site.
Do not make every section look identical.

LAYOUT:
Use a consistent max content width around 1200 to 1280px on desktop.
Use generous section spacing.
Desktop sections generally need 100 to 150px vertical breathing room.
Mobile needs around 64 to 88px.

Use 20 to 24px grid gaps where appropriate.
Cards should generally use 16 to 24px radius.
Do NOT use pill-shaped containers for everything.

Reserve pill shapes for:
- small tags
- filters
- compact category selectors
- occasional CTAs

Buttons can use moderate radius around 10 to 14px.

Use:
- editorial composition

- large photography
- oversized section numbers
- thin rules
- subtle red lines
- restrained borders
- image masks
- soft hover transitions
- carefully controlled scrolling
- subtle blur-to-focus transitions where meaningful

Avoid:
- glassmorphism
- excessive gradients
- random blobs
- floating 3D objects
- excessive shadows
- excessive rounded cards
- excessive icons
- generic stock medical illustrations
- decorative animations with no purpose
- WebGL
- Three.js

You may use Framer Motion, GSAP, CSS transitions, masks, transforms, opacity, blur and clip-path when they genuinely improve the experience.

Do not add new heavy libraries unless they are genuinely necessary.

PHOTOGRAPHY:

- 768 width

No content clipping.

ACCESSIBILITY:

Visible keyboard focus states.
Respect prefers-reduced-motion.
Buttons and tap targets must remain easy to use on mobile.

MOST IMPORTANT RULE:
Do not make the website impressive by adding more UI.
Make it impressive by removing unnecessary UI and improving hierarchy.

Before writing code, inspect the existing implementation and understand the current component structure.
Reuse the current architecture where possible.
Do not unnecessarily rewrite the entire application.

When modifying a section, only modify the target section unless a global token or shared component genuinely needs adjustment.

After implementing a section:
1. verify desktop
2. verify mobile
3. check spacing against surrounding sections
4. check visual hierarchy
5. check whether the section feels like part of one art-directed website
6. remove anything that feels decorative without purpose
